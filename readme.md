## ১. প্রজেক্ট পরিচিতি ও নির্দেশনা (Project Overview)

অভিনন্দন! তোমরা সফলভাবে প্রথম ৪টি মডিউলে HTML5 Semantics, CSS Box Model, Flexbox Layout, Tables, Forms ও Media Embeds শিখেছ। 

এটি তোমাদের প্রথম মাইলস্টোনের **চূড়ান্ত ক্যাপস্টোন প্রজেক্ট (Capstone Project)**। বাস্তব ক্লায়েন্ট কাজের মতো এখানে তোমাদের কোনো পূর্ব-লিখিত কোড (HTML/CSS) দেওয়া হয়নি। 
তোমাদের কাজ হলো:
1. উপরে দেওয়া `cafe-full-design.png` মকআপ ডিজাইনটি খুঁটিয়ে লক্ষ্য করা।
2. `images/` ফোল্ডারে থাকা খাদ্য ও ব্র্যান্ড অ্যাসেটগুলো ব্যবহার করা।
3. নিজে স্ক্র্যাচ থেকে `index.html` এবং `style.css` তৈরি করে সম্পূর্ণ ওয়েবসাইটটি ক্লাসের নির্দেশনা অনুযায়ী লাইভ কোডিং করে ফেলা।
4. সম্পূর্ণ ওয়েবসাইটটি গিটহাবে পুশ করে **GitHub Pages**-এ লাইভ হোস্ট করে বন্ধুদের সাথে লিঙ্ক শেয়ার করা।

## ৩. টাইপোগ্রাফি ও গুগল ফন্টস (Typography)

প্রজেক্টে গুগল ফন্ট **Open Sans** ব্যবহার করতে হবে। তোমাদের `index.html` ফাইলের `<head>` ট্যাগের ভেতরে নিচের লিঙ্কটি যুক্ত করো:

```html
<!-- Google Fonts: Open Sans -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Open+Sans:ital,wght@0,300..800;1,300..800&display=swap" rel="stylesheet">
```

সিএসএসে গ্লোবাল ফন্ট ফ্যামিলি সেট করো:
```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
  font-family: 'Open Sans', sans-serif;
}
```

## ৫. সেকশন রিকোয়ারমেন্ট চেকলিস্ট (Section-by-Section Checklist)

তোমাদের তৈরি করা পেজে নিচের ৭টি সেকশন অবশ্যই থাকতে হবে:

- [ ] **১. ফ্লেক্স ন্যাভিগেশন বার (Navbar):**
  - বামে ব্র্যান্ড লোগো `মিষ্টিমুখ` (অরেঞ্জ আইকন সহ)।
  - ডানে মেনু লিংক (হোম, আমাদের ঐতিহ্য, স্পেশালিটি, কম্বো অফার, মূল্য তালিকা) এবং সলিড অরেঞ্জ `বুক টেবিল` বাটন।
  - ফ্লেক্সবক্সের `justify-content: space-between; align-items: center;` ব্যবহার করতে হবে।

- [ ] **২. টু-কলাম হিরো ব্যানার (Hero Section):**
  - বামে বড় হেডলাইন ("বগুড়ার সেরা মিষ্টি ও তাজা বেকারির আনন্দ!"), সাবটেক্সট এবং ২টি অ্যাকশন বাটন (`মেন্যু দেখুন` ও `টেবিল বুক করুন`)।
  - ডানে `images/hero-platter.svg` ছবি।
  - ব্যাকগ্রাউন্ডে `images/header_bg.png` কার্ভ প্যাটার্ন।

- [ ] **৩. আমাদের ঐতিহ্য ও গল্প (Our Heritage):**
  - সেমান্টিক `<article>` দিয়ে তৈরি হোয়াইট শ্যাডো কার্ড।
  - বামে বগুড়ার খাঁটি দইয়ের ইতিহাস এবং ডানে ৩টি পিলার্স (১০০% খাঁটি দুধ, ঐতিহ্যবাহী মাটির হাঁড়ি, জিরো প্রিজারভেটিভ)।

- [ ] **৪. ৪টি সিগনেচার স্পেশালিটি কার্ড (Specialties Flex Grid):**
  - `display: flex; gap: 24px;` ব্যবহার করে ৪টি কার্ড পাশাপাশি সাজাও।
  - কার্ড ১: বগুড়ার শাহী দই (`images/doi.svg`)
  - কার্ড ২: জাফরানি রসমালাই (`images/rasmalai.svg`)
  - কার্ড ৩: ওভেন ফ্রেশ কুকিজ (`images/cookies.svg`)
  - কার্ড ৪: অ্যারাবিকা কফি (`images/coffee.svg`)
  - হোভারে কেবল বর্ডার কালার (`border-color: #FD6E0A`) এবং শ্যাডো পরিবর্তন হবে (কোনো ট্রান্সফর্ম অ্যানিমেশন ব্যবহার করবে না)।

- [ ] **৫. কম্বো প্যাকেজ ও মূল্য তালিকা (HTML Table):**
  - মডিউল ৪-এর টেবিল কনসেপ্টের পূর্ণাঙ্গ প্রয়োগ: `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`।
  - স্ট্রাইক-থ্রু রেগুলার প্রাইস এবং কোলস্প্যান (`colspan="6"`) দিয়ে ফ্রি ডেলিভারি ফুটনোট।

- [ ] **৬. টেবিল বুকিং ও প্রি-অর্ডার ফর্ম (HTML Form):**
  - `<fieldset>` এবং `<legend>` দিয়ে সাজানো পরিচ্ছন্ন ফর্ম।
  - ইনপুট টাইপ: নাম (`text`), মোবাইল (`tel`), ইমেইল (`email`), ব্রাঞ্চ ড্রপডাউন (`<select>`), তারিখ (`date`), সময় (`time`), অতিথি সংখ্যা (`number`), সিটিং এরিয়া রেডিও বাটন এবং বিশেষ অনুরোধের জন্য `<textarea>`।

- [ ] **৭. কিচেন ভিডিও, ম্যাপ ও ফুটার (Media & Footer):**
  - `<iframe>` দিয়ে ইউটিউব কিচেন ভিডিও ও গুগল ম্যাপ এম্বেড।
  - ৩-কলাম ফুটার: লোগো ও সোশ্যাল লিংক, ক্যাফে ওপেনিং আওয়ার্স এবং যোগাযোগের ঠিকানা।

## ৬. গিট ও গিটহাব পেজেস লাইভ নির্দেশিকা (Git & Deployment)

কাজ শেষ হলে টার্মিনালে নিচের কমান্ডগুলো দিয়ে প্রজেক্ট গিটহাবে আপলোড করো:

```bash
# ১. গিট ইনিশিয়ালাইজ করো
git init

# ২. সব ফাইল স্টেজিংয়ে যুক্ত করো
git add .

# ৩. অর্থপূর্ণ কমিট মেসেজ দাও
git commit -m "feat: complete MistiMukh Cafe website"

# ৪. মেইন ব্রাঞ্চ নিশ্চিত করো
git branch -M main

# ৫. তোমার গিটহাব রিপোজিটরির সাথে যুক্ত করো
git remote add origin https://github.com/YOUR_USERNAME/mistimukh-cafe.git

# ৬. গিটহাবে কোড পুশ করো
git push -u origin main
```

### গিটহাব পেজেসে লাইভ করার নিয়ম:
1. তোমার রিপোজিটরির **Settings** ট্যাবে যাও।
2. বাম পাশের মেন্যু থেকে **Pages** অপশনে ক্লিক করো।
3. **Build and deployment > Branch**-এ গিয়ে `None`-এর বদলে `main` সিলেক্ট করো এবং `Save` বাটনে ক্লিক করো।
4. ১-২ মিনিট পর তোমার সাইটের লাইভ লিঙ্ক পেয়ে যাবে: `https://YOUR_USERNAME.github.io/mistimukh-cafe/`।
